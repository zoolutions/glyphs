# Plans

Plans live as GitHub issues on zoolutions/glyphs — that is where every merged
change so far was specified. A file-mode plan (`/lode:plan --file`) goes to
`docs/plans/YYYY-MM-DD-<slug>.md`; the directory does not exist yet and is
created on first use. It sits inside the docs app's tree but outside its
registry, so it is not a docs page and is not routed.

Session handovers and gate reports go in `../tmp/`, which is git-ignored.
